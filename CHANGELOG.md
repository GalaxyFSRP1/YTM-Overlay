# Changelog

## v0.0.0 beta — first public release

- Initial public beta of the Windows/OBS YouTube Music overlay.
- Playback clock, browser queue link, independent overlay sources, lyric lookup and manual lyrics.
- Twitch, YouTube Live and Kick browser-chat request adapters with approval or automatic acceptance.
- Request moderation, cooldown and duplicate checks, history, and a separate requests-only OBS source.
- Opt-in experimental addition to a linked YouTube Music browser queue; acceptance alone is not a player queue operation.
- Self-contained Windows x64 executable using .NET 10 LTS.

This beta uses unofficial page integrations and has the limitations documented in the README and release notes.
