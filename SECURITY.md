# Security

This beta is intended for a single trusted Windows user. Its HTTP server binds to loopback, but local applications can access local control pages. Browser bookmarks contain private pairing keys; local-network permission applies to the whole site.

Please do not post pairing keys, bookmark code, cookies, stream keys, private request history or personal data in public issues. If the repository owner enables GitHub private vulnerability reporting, use **Security → Report a vulnerability**. Otherwise ask the owner for a private reporting method before sharing sensitive details.

The owner should keep the bundled .NET runtime and build SDK patched, rebuild releases when security updates are available, and review the security/privacy sections in the README before publishing.
