CHAT LINKS · v0.0.1 BETA

Bring your chat to the request inbox.

Use one private bookmark for each live chat tab. No OAuth keys or bot accounts are needed. This is an experimental browser-page reader; site layout changes can break it.

1
Make the bookmark.

In Chrome, Edge or Brave, show bookmarks with Ctrl + Shift + B. Drag the button to the bookmarks bar.

♫ YTM Chat Requests  

If dragging is blocked, create a new bookmark and paste the copied code into its URL field—not the address bar.

2
Open your own live chat.

Twitch: open your channel’s chat or its pop-out chat.
Kick: open your channel page with its chat visible.
YouTube Live: on your live video choose the chat menu → Popout chat; switch to that separate chat window/tab. The bookmark cannot read an embedded cross-origin chat iframe.

3
With chat already loaded, click the bookmark on that chat page.

If prompted, allow access to Apps on device or local-network/loopback access. Keep the chat page open. Repeat steps 2–3 on each platform you use.

4
Open the request dashboard.

Turn on Accept new chat requests, choose approval or automatic mode, and save. Wait a few seconds after linking; then ask a viewer to send !sr Song title - Artist or a single YouTube video link. Existing chat history is deliberately ignored.

5
Optional: connect the actual player.

Use Connect YouTube Music in your music tab, start a song, then opt into experimental player insertion on the dashboard. Without this, accepted songs remain a separate list and can be opened manually.

Good to know

A chat link remains active only while that tab and the app stay open. After a refresh or navigation, click the bookmark again. Clicking an active bookmark stops its link. The green dashboard dot confirms a heartbeat, not that every chat row was parsed. The adapters read only ordinary text messages visible in the page, not Super Chats, deleted events, whisper messages, or replies to viewers. Repeated identical messages in one link session may be deduplicated. Bots, blocked links, site changes, hidden tabs, and browser throttling can cause missed messages.

In YouTube chat, switch from Top chat to Live chat to reduce filtering. For Kick/Twitch, make sure the chat is visible and has fully loaded before linking. If a platform changes its page layout, use the dashboard’s manual add while it is repaired.

The bookmark contains a private local pairing key. Don’t share it. Device/loopback permission applies to the whole site, not just this application, and may allow it to reach other local services; grant it only if you trust that site. Revoke it in browser site settings. If the port changes, recreate the bookmark.

Only request commands, viewer display names, and the chat page path are sent to the local app; the app stores accepted/rejected requests on your PC. Neither chat passwords, cookies nor stream keys are sent. Your browser continues to use each platform normally. Use only in chats you are authorized to monitor.
